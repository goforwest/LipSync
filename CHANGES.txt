Version 4.2.0 | 2026-Oct-13
- Cut serial settings API command latency: messages are now framed by a non-blocking line parser — newline-terminated messages are processed the instant they arrive, and legacy bare messages keep a 50 ms idle-gap frame — removing readString()'s timed busy-wait that padded every exchange with a fixed delay (1 s at the Stream default; ~2 s per command, ~30 s for LipSync Connect's settings load, now ~2 s)
- Hardened the hardware watchdog: it is now armed on every boot, including safe mode and watchdog-reset boots; a run of 3 consecutive watchdog resets (tracked in the GPREGRET2 retention register) stops re-arming so a wedged device settles in safe mode instead of resetting forever, and the budget restores after 2 minutes of uptime
- Sip and puff robustness: the once-a-minute pressure offset re-measure (and the boot-time one) now gathers its five samples one per polling tick instead of blocking the main loop for up to 15 s when a sensor misbehaves; sensors that return consecutive invalid readings are marked unhealthy — the I2C bus is left alone until a 2 s re-probe succeeds — so a flaky mouthpiece sensor can no longer stall the device, and stale readings can never fire a phantom sip or puff
- Added a patched Wire library (vendored in Build_Files/Firmware_Files/Libraries/Wire, used automatically by the CI and local builds): every nRF52 I2C transaction wait is bounded at 50 ms, and a wedged bus is recovered in place with a bounded STOP plus the NXP I2C bus-clear (up to 9 SCL clocks) — a sensor holding the bus mid-transaction now fails its read immediately instead of hanging the device until the watchdog resets it (relates to upstream issues #73 and #75)
- Hub menu and feedback no longer block the main loop: the informational screen pages (exit, mode change, center-reset and calibration completion, full-calibration and factory-reset confirmations, long-text scroll) dwell on a scheduled timer transition, and multi-tone sounds (ready, error) sequence through a note queue — the serial API, joystick and pressure polling stay live during page dwells and sound playback (the pre-restart shutdown sound keeps its deliberate blocking sequence)

Version 4.1.0 | 2025-March-31
- Software bug fixes and added features 
	- TinyUSB Library bug fixed, now works with latest version (3.4.2) of the library
	- Full calibration changes
		- Moved to "More" menu to prevent Full Calibration from being selected when not necessary
		- Added warning message and confirmation page
		- Added error checking, if joystick was not moved enough during full calibration, use default value instead
	- No USB auto mode switch fix
		- 4.0.1 added a feature that if no USB was detected the LipSync would automatically switch to Bluetooth mode, but this caused unintentional effects 
		- Now, if no USB is detected, the screen displays an error message and buzzer plays an error tone, but continues to try to connect in the background
		- To change modes, the menu can now be used even if no USB is mounted.
	- i2c error checking
	- Light Brightness can now be adjusted through Hub menu or API
	- Scroll speed can now be adjusted through Hub menu
	- Scroll is now calculated differently, at a higher poll rate but not performed every loop, depending on the scroll speed
	- Fixed bug where scroll speed was dependent on cursor speed
	- Fixed bug in timers, so timer offset now works properly
	- Deadzone changes
		- Outer deadzone has its own variable and is independent of inner deadzone
		- Output now starts at 0% at the end of the innder deadzone, and goes to 100% at the edge of the outer deadzone
	- Added additional sounds for startup, powering off, and errors
	- Added watchdog implementation
	- Added safe mode accessible by Hub Buttons, or triggered during hardware error or watchdog
- Hardware changes
	- Ribs were added to the screw bosses on the LipSync Hub Top and LipSync Hub Bottom to increase strength
	- LipSync Mouthpiece was simplified
		- The updated mouthpiece is comprised of the same hydrophobic syringe filter, a Luer adapter, and a large silicone straw. This simplified design is easier to assemble, easier to clean, and has the added benefit of reducing the overall cost.
- Documentation updates
	- Maker Guide
		- TinyUSB library - can now use latest version (3.4.2)
		- Added additional assembly step to test joystick components before assembly into Joystick Gimbal and housing
	- User Guide
		- Updated to reflect changes to menu structure and full calibration process
		- Expanded troubleshooting with error messages
	- Created LipSync Firmware Upgrade Guide
	- Created LipSync Information Sheet
