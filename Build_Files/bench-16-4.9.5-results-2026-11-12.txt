B13 (keep-open / bounce storm) — NOT RE-RUN, and deliberately so: it is
          unchanged between 4.9.4 and 4.9.5 (the 4.9.5 diff touches only the
          latch guard, the horizon-anchor extraction/doc, the test file and
          comments), and it was proven exhaustively on 4.9.4 (80 consecutive
          bounces with the window alive; the RPA racer bounced in 0.4 s; the
          target admitted 2.0 s into a window immediately after a bounce).
          The B2/B3 window+bounce machinery did re-run cleanly here, which is
          the same code path.

4.9.5-SPECIFIC GAP, ACCEPTED: the mid-window latch fix (the 4.9.5 minor) was
          NOT radio-proven by this run.  Proving it needs a precisely timed
          physical SCROLL hold engaged DURING a window and the proof is
          indirect (whether the next input emits an IA,0 dispatch line —
          outputAction has no wire readout).  The fix is a small, tightly
          traced host-identity edge whose non-window behavior is byte-identical
          to 4.9.4 (bench-proven); recorded here as the one accepted residual.

VERDICT: 11 of 11 wire-settled steps PASS on 4.9.5.  No regressions found.  The
release stands as tagged.
